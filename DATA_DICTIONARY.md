# Gold data dictionary

The Gold layer is the `wh_gold` Warehouse in the **NYC Urban Analytics** Fabric workspace. Column types below describe how to interpret values. The schema query at the end returns the physical SQL types and nullability from Fabric. The keys listed here describe the expected row grain and how the tables join.

## Tables and keys

| Table | One row per | Logical key | Main input |
| --- | --- | --- | --- |
| `dbo.FactTaxiDaily` | NYC local pickup date and TLC pickup zone | `date_key`, `pickup_location_id` | `lh_silver.dbo.taxi_trips` |
| `dbo.FactAirQualityDaily` | NYC local date and source-specific sensor or monitor | `date_key`, `sensor_key` | `lh_silver.dbo.air_quality_daily` and `lh_silver.dbo.epa_no2_daily` |
| `dbo.DimDate` | Calendar date | `date_key` | Calendar generated by the warehouse load |
| `dbo.DimZone` | TLC taxi zone | `location_id` | `lh_silver.dbo.taxi_zones` |
| `dbo.DimFX` | Calendar date and currency pair | `date_key`, `base_currency`, `quote_currency` | `lh_silver.dbo.fx_rates_daily` and `DimDate` |
| `dbo.DimGDP` | Country and year | Country code and year | `lh_silver.dbo.gdp_annual` |

## FactTaxiDaily

Trips are grouped by pickup date and zone. The load uses the deduplicated Silver rows whose pickups fall within the source month (`is_outside_source_month = 0`).

| Column | Type or unit | Meaning |
| --- | --- | --- |
| `date_key` | Integer, `YYYYMMDD` | Pickup date key. Joins to `DimDate.date_key`. |
| `pickup_location_id` | Integer | TLC pickup zone ID. Joins to `DimZone.location_id`. Unmatched zone IDs are assigned to `264`. |
| `trip_count` | Integer count | All eligible trips in the group, including trips with zero reported distance. |
| `total_amount_usd` | Decimal, USD | Sum of reported `total_amount`. This is the total amount charged to passengers and excludes cash tips. |
| `amount_trip_count` | Integer count | Number of trips with a reported `total_amount`. Denominator for average total per trip. |
| `distance_sum_miles` | Decimal, miles | Sum of positive, non-null trip distances. |
| `valid_distance_trip_count` | Integer count | Number of trips contributing to `distance_sum_miles`. |
| `duration_sum_seconds` | Integer, seconds | Sum of positive pickup-to-drop-off durations. |
| `valid_duration_trip_count` | Integer count | Number of trips contributing to `duration_sum_seconds`. |
| `fare_sum_usd` | Decimal, USD | Sum of reported `fare_amount`, the metered fare. |
| `fare_trip_count` | Integer count | Number of trips with a reported `fare_amount`. Denominator for average metered fare. |

The fare and total sums use the reported monetary values, including negative amounts when present. A sum can be `NULL` when every input to it is missing or ineligible. Use the matching count for each sum and return `NULL` when the denominator is zero.

## FactAirQualityDaily

The fact combines OpenAQ PM2.5 and EPA AQS NO₂ measurements. The source is part of the sensor key because identifier systems differ.

| Column | Type or unit | Meaning |
| --- | --- | --- |
| `date_key` | Integer, `YYYYMMDD` | Local observation date. Joins to `DimDate.date_key`. |
| `source_system` | Text | Data provider, such as `openaq` or `epa_aqs`. |
| `sensor_key` | Text | Source-qualified identifier used for grouping and joins. For example, `openaq:673` identifies the CCNY PM2.5 sensor. |
| `sensor_id` | Integer | OpenAQ sensor ID or the numeric monitor identifier derived by the EPA load. |
| `location_id` | Integer | OpenAQ location ID or the numeric site identifier derived by the EPA load. Stored in the air-quality identifier system. |
| `station_name` | Text | Display name of the monitoring station. |
| `pollutant` | Text | Pollutant code, such as `pm25` or `no2`. |
| `unit` | Text | Unit of concentration. PM2.5 uses µg/m³ and NO₂ uses ppb in this project. |
| `daily_mean` | Numeric, in `unit` | Reported mean concentration for the local observation day. |
| `observed_hours` | Integer, hours | Number of hours observed in the daily record. |
| `expected_hours` | Integer, hours | Number of hours expected for the source day. |
| `coverage_ratio` | Numeric ratio | Observed hours divided by expected hours. For example, `0.75` means 75% coverage. |
| `has_invalid_daily_mean` | Boolean flag | Marks measurements classified as invalid by the Silver transformation. |

Filter to the same pollutant and unit for concentration comparisons. The year-over-year and borough analyses use valid daily means with at least 75% coverage. A date with no measurement remains missing. To compare with taxi demand, use the notebook's monitor-to-borough mapping, aggregate taxi pickups by date and borough, then join by date and borough.

## DimDate

The current calendar runs from **2022-01-01** through **2024-02-29**, inclusive. Fact coverage depends on the source files.

| Column | Type or unit | Meaning |
| --- | --- | --- |
| `date_key` | Integer, `YYYYMMDD` | Calendar date key shared by both facts and `DimFX`. |
| `calendar_date` | Date | Calendar date. |
| `calendar_year` | Integer | Four-digit calendar year. |
| `calendar_quarter` | Integer | Calendar quarter, 1–4. |
| `calendar_month` | Integer | Calendar month, 1–12. |
| `day_of_month` | Integer | Day within the month, 1–31. |
| `is_weekend` | Boolean flag | Saturday or Sunday. |

## DimZone

| Column | Type or unit | Meaning |
| --- | --- | --- |
| `location_id` | Integer | TLC zone identifier referenced by the taxi fact. |
| `borough` | Text | Borough or area label in the TLC lookup. |
| `zone_name` | Text | TLC zone name. |
| `service_zone` | Text | TLC service-zone classification. |

City-only rankings filter to the five NYC boroughs. The lookup also allows labels outside that set.

## DimFX

The project uses the ECB daily series `EXR.D.USD.EUR.SP00.A`. When the ECB has no rate for a calendar date, Gold takes the most recent available rate at or before that date.

| Column | Type or unit | Meaning |
| --- | --- | --- |
| `date_key` | Integer, `YYYYMMDD` | Date to which the rate applies. Joins to `DimDate.date_key`. |
| `base_currency` | Text | Base currency, `EUR` for the project series. |
| `quote_currency` | Text | Quote currency, `USD` for the project series. |
| `usd_per_eur` | Decimal, USD per EUR | Number of US dollars per euro. Divide a USD amount by this rate to obtain EUR. |
| `rate_source_date` | Date | Date on which the applied ECB rate was published. |
| `is_carried_forward` | Boolean flag | Marks a rate carried forward from an earlier date. |

## DimGDP

The World Bank series `NY.GDP.MKTP.CD` gives annual nominal GDP in current US dollars. The project snapshot holds United States data for 2000–2024.

| Field | Type or unit | Meaning |
| --- | --- | --- |
| Country code and name | Text | Country identifier and display name. The project uses `USA`, United States. |
| `gdp_year` | Integer | Reporting year. Use the year and country when joining to annual context. |
| `gdp_usd` | Numeric, current USD | Nominal GDP value in US dollars. Use billions only as a display scale. |

GDP stays at country-year grain. Aggregate trip metrics to year before adding it as context and specify that the available taxi observations cover January and February of the corresponding year.

## Metric formulas

| Metric | Calculation |
| --- | --- |
| Number of pickups | Sum `trip_count` across the selected dates and zones. |
| Average metered fare in USD | Sum `fare_sum_usd` and divide by the sum of `fare_trip_count`. |
| Average total per trip in USD | Sum `total_amount_usd` and divide by the sum of `amount_trip_count`. |
| Average trip distance | Sum `distance_sum_miles` and divide by the sum of `valid_distance_trip_count`. |
| Average trip duration in minutes | Sum `duration_sum_seconds`, divide by the sum of `valid_duration_trip_count`, then divide by 60. |
| Total trip amount in EUR | Sum USD amounts per day, divide each daily total by that date's `usd_per_eur`, then sum the results. |
| Average total per trip in EUR | Divide the total EUR amount by the sum of `amount_trip_count` for the same dates with rates. |

## Check the physical schema

Run this read-only query in `wh_gold` to list the columns, data types, and nullability visible to your account. [Microsoft Learn](https://learn.microsoft.com/en-us/sql/relational-databases/system-information-schema-views/columns-transact-sql?view=fabric)

```sql
SELECT
    TABLE_NAME AS table_name,
    ORDINAL_POSITION AS column_position,
    COLUMN_NAME AS column_name,
    DATA_TYPE AS data_type,
    CHARACTER_MAXIMUM_LENGTH AS max_length,
    NUMERIC_PRECISION AS numeric_precision,
    NUMERIC_SCALE AS numeric_scale,
    IS_NULLABLE AS is_nullable
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'dbo'
  AND TABLE_NAME IN (
      'FactTaxiDaily', 'FactAirQualityDaily',
      'DimDate', 'DimZone', 'DimFX', 'DimGDP'
  )
ORDER BY TABLE_NAME, ORDINAL_POSITION;
```
